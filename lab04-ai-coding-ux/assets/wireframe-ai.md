# Text Wireframe (ASCII Layout) - ระบบคลังสินค้า (Inventory Management)

เอกสารนี้รวบรวมแบบร่างโครงสร้างหน้าจอ (ASCII Layout) จำนวน 3 หน้า ได้แก่ **Login**, **Dashboard** และ **Add Product** โดยออกแบบเพื่อตอบโจทย์พนักงานคลังสินค้าที่มีทักษะเทคโนโลยีระดับ 2/5 เน้นหลักการ **Usability** และ **Accessibility (WCAG AA)** พร้อมรองรับสินค้าทั้ง 2 ชนิด (สินค้าที่จับต้องได้ และ สินค้าดิจิทัล)

---

## 1. หน้า Login (เข้าสู่ระบบ)

### ASCII Wireframe
```text
+-----------------------------------------------------------------------+
|  [LOGO] ระบบจัดการคลังสินค้าและหนังสือดิจิทัล (Smart Inventory)         |
+-----------------------------------------------------------------------+
|                                                                       |
|                     +-------------------------------+                 |
|                     |         เข้าสู่ระบบ           |                 |
|                     +-------------------------------+                 |
|                                                                       |
|   ชื่อผู้ใช้งาน (Username) *                                          |
|   +---------------------------------------------------------------+   |
|   | sommai.r                                                      |   |
|   +---------------------------------------------------------------+   |
|                                                                       |
|   รหัสผ่าน (Password) *                                               |
|   +-------------------------------------------------------+-------+   |
|   | ••••••••••••                                          | [แสดง] |   |
|   +-------------------------------------------------------+-------+   |
|   [!] ข้อผิดพลาด: รหัสผ่านไม่ถูกต้อง กรุณาตรวจสอบแป้น Caps Lock      |
|                                                                       |
|   [ ] จดจำฉันในระบบนี้                                               |
|                                                                       |
|   +---------------------------------------------------------------+   |
|   |                  [ เข้าสู่ระบบ (Login) ]                      |   |
|   +---------------------------------------------------------------+   |
|                                                                       |
|             ลืมรหัสผ่าน? ติดต่อผู้ดูแลระบบ (Admin) โทร. 1102          |
|                                                                       |
+-----------------------------------------------------------------------+
```

### คำอธิบาย Usability & Accessibility
- **Visible Label**: มีป้ายข้อความกำกับเหนือช่องกรอกเสมอ ไม่ใช้แค่ placeholder จาง ๆ
- **Required Indicator**: มีเครื่องหมาย `*` ชัดเจนสำหรับข้อมูลที่จำเป็นต้องกรอก
- **Descriptive Error**: ข้อความแจ้งเตือนข้อผิดพลาดมีไอคอน `[!]` ประกอบ และมีข้อความแนะนำวิธีแก้ไข (เช่น เช็ก Caps Lock)
- **High Contrast Button**: ปุ่ม "เข้าสู่ระบบ (Login)" มีข้อความระบุหน้าที่ชัดเจน ขนาดใหญ่ คลิกง่าย

## 2. หน้า Dashboard (ภาพรวมระบบและแจ้งเตือน)

### ASCII Wireframe
```text
+-----------------------------------------------------------------------+
|  [LOGO] Smart Inventory    [ คลังสินค้า ]  [ รายงาน ]   |  ผู้ใช้: สมหมาย [ออก] |
+-----------------------------------------------------------------------+
|  ภาพรวมคลังสินค้า (Dashboard Overview)                                |
|                                                                       |
|  +---------------------+ +---------------------+ +------------------+ |
|  | มูลค่ารวมในคลัง     | | สินค้าจับต้องได้    | | ไฟล์ดิจิทัล (E-book)|
|  | ฿ 2,450,000         | | 124 รายการ (4,820ชิ้น)| | 58 รายการ (Unlimited)|
|  +---------------------+ +---------------------+ +------------------+ |
|                                                                       |
|  [!] การแจ้งเตือน: สินค้าใกล้หมดสต็อก (Low Stock Alert <= 5 ชิ้น)     |
|  +------------------------------------------------------------------+ |
|  | [!] หนังสือการเขียนโปรแกรม Python คงเหลือ 2 เล่ม [สั่งเพิ่มด่วน] | |
|  | [!] คู่มือวิศวกรรมซอฟต์แวร์ คงเหลือ 4 เล่ม       [สั่งเพิ่มด่วน] | |
|  +------------------------------------------------------------------+ |
|                                                                       |
|  รายการสินค้าล่าสุด (Recent Inventory Items)      [ + เพิ่มสินค้าใหม่ ]|
|  +------------------------------------------------------------------+ |
|  | รหัส | ชื่อสินค้า              | ชนิดสินค้า | ยอดคงเหลือ | สถานะ    | |
|  |------+-------------------------+------------+------------+---------| |
|  | B001 | Python Programming Book | Physical   | 2 เล่ม     | [เตือน] | |
|  | E042 | Clean Code E-Book (PDF) | Digital    | ไม่จำกัด   | [ปกติ]  | |
|  | B005 | Web Architecture Guide  | Physical   | 45 เล่ม    | [ปกติ]  | |
|  +------------------------------------------------------------------+ |
+-----------------------------------------------------------------------+
```

### คำอธิบาย Usability & Accessibility
- **Clear Product Distinction**: มีการแยกกลุ่มและแสดงคอลัมน์ "ชนิดสินค้า" (Physical vs Digital) อย่างเด่นชัด ทำให้พนักงานแยกแยะได้ทันทีโดยไม่ต้องคาดเดาจากชื่อ
- **Prominent Action Button**: ปุ่ม `[ + เพิ่มสินค้าใหม่ ]` วางไว้ด้านขวาบนของตาราง มองเห็นง่าย
- **Accessible Low Stock Alert**: มีบล็อกแจ้งเตือนสถานะสินค้าต่ำกว่าเกณฑ์ ใช้ทั้งแถบสีและไอคอน `[!]` ชัดเจนตามเกณฑ์ WCAG

## 3. หน้า Add Product (เพิ่มข้อมูลสินค้าใหม่)

### ASCII Wireframe
```text
+-----------------------------------------------------------------------+
|  [LOGO] Smart Inventory > จัดการคลังสินค้า > เพิ่มสินค้าใหม่           |
+-----------------------------------------------------------------------+
|  เพิ่มรายการสินค้าใหม่ (Add New Product)                              |
|                                                                       |
|  (v) บันทึกสำเร็จ: บันทึกข้อมูลสินค้า "Python Pro" เข้าระบบเรียบร้อยแล้ว   |
|                                                                       |
|  1. ชนิดของสินค้า (Product Type) *                                    |
|     (•) สินค้าที่จับต้องได้ (Physical Goods - นับสต็อกคงเหลือ)        |
|     ( ) สินค้าดิจิทัล/ไฟล์ (Digital Goods/E-book - ดาวน์โหลดหลังชำระ) |
|                                                                       |
|  2. ชื่อสินค้า (Product Name) *                                       |
|  +------------------------------------------------------------------+ |
|  | Python Pro ฉบับเข้มข้น                                           | |
|  +------------------------------------------------------------------+ |
|                                                                       |
|  3. รหัสสินค้า (SKU / Code) *                                         |
|  +------------------------------------------------------------------+ |
|  | BK-PY-009                                                        | |
|  +------------------------------------------------------------------+ |
|                                                                       |
|  4. หมวดหมู่สินค้า (Category) *                                       |
|  +---------------------------------------------------------------+--+ |
|  | หนังสือเทคโนโลยีคอมพิวเตอร์                                    |v | |
|  +---------------------------------------------------------------+--+ |
|                                                                       |
|  5. ราคาขายต่อหน่วย (Price - บาท) *                                   |
|  +------------------------------------------------------------------+ |
|  | 450.00                                                           | |
|  +------------------------------------------------------------------+ |
|  [!] กรุณากรอกราคาขายเป็นตัวเลขที่มากกว่า 0                           |
|                                                                       |
|  6. จำนวนสต็อกเริ่มต้น (Quantity) *                                    |
|  +------------------------------------------------------------------+ |
|  | 50                                                               | |
|  +------------------------------------------------------------------+ |
|  *(หากเลือกสินค้าดิจิทัล ช่องนี้จะถูกปิดใช้งานอัตโนมัติเนื่องจากไม่จำกัดยอด)*|
|                                                                       |
|  7. แนบไฟล์ดิจิทัล (เฉพาะสินค้าดิจิทัล)                                |
|  +------------------------------------------------------------------+ |
|  | [ เลือกไฟล์ PDF / EPUB ] ไม่ได้เลือกไฟล์ใด                        | |
|  +------------------------------------------------------------------+ |
|                                                                       |
|                                  [ ยกเลิก ]   [ บันทึกสินค้าใหม่ (Save) ]|
+-----------------------------------------------------------------------+
```

### คำอธิบาย Usability & Accessibility
- **Static Visible Label**: ทุกฟิลด์มี Label อยู่ด้านบนตลอดเวลา พร้อมเครื่องหมาย `*` แสดงฟิลด์บังคับกรอก
- **Radio Selection for Dual Types**: ให้เลือกประเภทสินค้าตั้งแต่ต้น หากเลือกสินค้าดิจิทัล ช่องจำนวนสต็อกจะถูก disable เพื่อป้องกันผู้ใช้สับสนและกรอกข้อมูลเพี้ยน
- **Dual Visual Error Feedback**: แสดงข้อความ Error ใต้ฟิลด์เฉพาะจุด พร้อมไอคอน `[!]` และบอกวิธีแก้ไขที่เข้าใจง่าย
- **Clear Button Hierarchy**:
  - ปุ่มรอง `[ ยกเลิก ]` (Secondary, สีเทา/ขอบบาง)
  - ปุ่มหลัก `[ บันทึกสินค้าใหม่ (Save) ]` (Primary, สีน้ำเงิน `#1E40AF`, ตัวอักษรสีขาว ข้อความเจาะจงชัดเจน ไม่ใช้แค่ "ตกลง" หรือ "OK")
